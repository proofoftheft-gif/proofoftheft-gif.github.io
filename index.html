The channel

Proof of Theft is a YouTube documentary channel. Hash, a cold wallet, follows money that doesn't want to be found: crypto hacks, exchange breaches and on-chain thefts, rebuilt as animated case files from blockchain records and public statements. Every source is listed in each video's description.

About the "Proof of Theft Buzz" app

"Proof of Theft Buzz" is a private tool used only by the channel's owner. It connects to the YouTube Data API and the YouTube Analytics API for this one channel, so the owner can read the channel's analytics and update this channel's own video details. Every change is made only after the owner approves it. It is not offered to anyone else.
